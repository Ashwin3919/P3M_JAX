┌─────────────────────────────────────────────────────────────────────────┐
│                         python main.py --config X.json                  │
└─────────────────────────────┬───────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────────────────┐
│  1. LOAD CONFIG                  load_config(config_path)               │
│     • Parse JSON                                                         │
│     • Validate keys, ranges, p3m cutoff < L/2                           │
│     • Set precision (float16/32/64) + jax_enable_x64 if needed          │
└─────────────────────────────┬───────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────────────────┐
│  2. BUILD WORLD                                                          │
│                                                                          │
│   Cosmology(H0, OmegaM, OmegaL)                                         │
│     └─ da(a) = a·H(a)     G = (3/2)·ΩM·H0²                             │
│                                                                          │
│   B_mass  = Box(dim, N,   L)   ← mass grid    N^dim cells               │
│   B_force = Box(dim, 2N,  L)   ← force grid  (2N)^dim cells  (2× res)  │
│     └─ precompute K (wavenumber array), k, k_min, k_max                 │
└─────────────────────────────┬───────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────────────────┐
│  3. INITIAL CONDITIONS           Zeldovich(B_mass, B_force, cosmo, phi) │
│                                                                          │
│   garfield(B_mass, seed)                                                 │
│     └─ white_noise → FFT → × √P(k) × Potential(k) → IFFT → φ(x)       │
│          P(k) = Power_law(n_s) × Scale(σ) × Cutoff(k_Nyq)              │
│                                                                          │
│   Zeldovich displacement:  u = -∇φ / Δx   (4th-order FD gradient)      │
│   Positions:   x = grid_pos + a_start · R_D · u                         │
│   Momenta:     p = a_start · f · R_D · u                                │
│     R_D = D_cosmo(a) / D_EdS(a)   (growth-factor ratio, Heath 1977)    │
│                                                                          │
│   → State(time=a_start, position, momentum)                             │
└─────────────────────────────┬───────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────────────────┐
│  4. BUILD PHYSICS SYSTEM         PoissonVlasov(B_force, cosmo, m_p)     │
│                                                                          │
│   Precompute Poisson kernel (once, at init):                            │
│     kernel = (Potential() / CICWindow²)(B_force.K)                      │
│            = -1/k²  ÷  ∏ sinc²(k_d·Δx/2π)   [deconvolved for CIC]     │
│   (or TSCWindow³ if assignment="tsc")                                   │
│                                                                          │
│   particle_mass m_p = (N_force / N_mass)^dim                            │
└─────────────────────────────┬───────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────────────────┐
│  5. JIT-COMPILE CHUNK FUNCTION   (done ONCE before the loop)            │
│                                                                          │
│   Fixed:    jit( partial(step_chunk, system, dt=dt, save_every=k) )     │
│   Adaptive: jit( partial(step_chunk_adaptive, system, C_cfl, eps, ...) )│
│                                                                          │
│   First call triggers XLA trace → compile → hardware binary             │
│   All subsequent chunks reuse the binary (zero Python overhead)         │
└─────────────────────────────┬───────────────────────────────────────────┘
                              │
                              ▼
╔═════════════════════════════════════════════════════════════════════════╗
║  6. CHUNK LOOP   for chunk_idx in range(n_chunks):  [Python level]     ║
╚═════════════════════════════╦═══════════════════════════════════════════╝
                              ║
                              ▼
┌─────────────────────────────────────────────────────────────────────────┐
│  step_chunk  ──────────────────────────────────────────────────────     │
│    lax.scan over save_every steps:                                       │
│                                                                          │
│    ┌──────── leap_frog(dt, system, state) ──────────────────────────┐   │
│    │                                                                  │   │
│    │  HALF KICK:  p_half = p + (dt/2)·dp/da                         │   │
│    │              a_half = a + dt/2                                  │   │
│    │                                                                  │   │
│    │  ┌──── momentumEquation(state) ────────────────────────────┐   │   │
│    │  │                                                           │   │   │
│    │  │  PM FORCE (always):                                       │   │   │
│    │  │    x_grid = pos / Δx                                      │   │   │
│    │  │    ρ = md_cic_nd(shape, x_grid)    ← CIC scatter         │   │   │
│    │  │    δ = ρ·m_p - 1                   ← density contrast    │   │   │
│    │  │    δ̂ = fftn(δ)                                           │   │   │
│    │  │    φ̂ = δ̂ × kernel                 ← Poisson solve       │   │   │
│    │  │    φ = ifftn(φ̂).real × G/a                              │   │   │
│    │  │    g = gradient_4th_order(φ, axis) ← 4-point FD stencil │   │   │
│    │  │    acc_PM = InterpND(g)(x_grid)    ← CIC gather          │   │   │
│    │  │                                                           │   │   │
│    │  │  PP FORCE (if solver="p3m"):                              │   │   │
│    │  │    codes = morton_encode(x_grid)   ← interleave bits     │   │   │
│    │  │    order = argsort(codes)          ← sort by Z-curve     │   │   │
│    │  │    vmap over all particles i:                             │   │   │
│    │  │      gather ±W neighbours from sorted array              │   │   │
│    │  │      r_vec = min-image separation  ← periodic BC         │   │   │
│    │  │      F = G·m_p/a · erfc(r/α) · r / |r_soft|³            │   │   │
│    │  │      mask: r < r_cut, not-self, in-bounds                │   │   │
│    │  │    unsort → acc_PP                                        │   │   │
│    │  │                                                           │   │   │
│    │  │  return -(acc_PM + acc_PP) / H(a)                        │   │   │
│    │  └───────────────────────────────────────────────────────────┘   │   │
│    │                                                                  │   │
│    │  DRIFT:  x_new = x + dt·(p_half / a_half²·H(a_half))           │   │
│    │                                                                  │   │
│    │  HALF KICK:  p_new = p_half + (dt/2)·dp/da  (at a_new)         │   │
│    │                                                                  │   │
│    │  return State(a+dt, x_new, p_new)                               │   │
│    └──────────────────────────────────────────────────────────────────┘   │
│                                                                          │
│  (Adaptive: lax.while_loop recomputes dt each step via CFL condition)   │
└─────────────────────────────┬───────────────────────────────────────────┘
                              │

────────────────────────────────────────────────────────────────────────────
  KEY LAYERS
────────────────────────────────────────────────────────────────────────────

  Layer                       Who runs it          How often
  ─────────────────────────   ──────────────────   ───────────────────────
  Python config + setup       CPU, Python          Once
  jax.jit compilation         XLA compiler         Once (first chunk call)
  lax.scan leapfrog           XLA, fused kernel    save_every steps/chunk
  momentumEquation (PM/PP)    XLA, inside scan     Every leapfrog step
  Per-chunk I/O               CPU, Python          Once per chunk
  End-of-run plots            CPU, matplotlib      Once

  The critical insight: only the lax.scan body (leapfrog + force pipeline)
  runs on accelerator hardware. Everything around it — config, I/O, plot
  generation, the Python "for chunk_idx" loop — is pure CPU Python
  orchestration. JAX only "sees" what is inside step_chunk.
